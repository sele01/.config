# Lazygit Daily Reference Card

## Panel Navigation
| Key | Action |
|-----|--------|
| `1` | Status panel |
| `2` | Files panel |
| `3` | Branches panel |
| `4` | Commits panel |
| `5` | Stash panel |
| `Tab` | Next panel |
| `Shift + Tab` | Previous panel |

## Staging Files
| Key | Action |
|-----|--------|
| `Space` | Stage/unstage file |
| `a` | Stage all files |
| `d` | Discard changes (careful!) |
| `Enter` | View file diff |

## Committing
| Key | Action |
|-----|--------|
| `c` | Commit staged changes |
| `C` | Commit with git editor |
| `A` | Amend last commit |
| `Shift + A` | Amend commit with editor |

## Branches
| Key | Action |
|-----|--------|
| `n` | New branch |
| `Space` | Checkout branch |
| `M` | Merge into current branch |
| `d` | Delete branch |
| `r` | Rebase branch |

## Pushing & Pulling
| Key | Action |
|-----|--------|
| `p` | Pull from remote |
| `P` | Push to remote |
| `Shift + P` | Force push |
| `f` | Fetch from remote |

## Stashing
| Key | Action |
|-----|--------|
| `s` | Stash changes |
| `g` | Pop stash |
| `d` | Drop stash |

## Undo & Redo
| Key | Action |
|-----|--------|
| `z` | Undo last action |
| `Shift + Z` | Redo last undo |

## Diff View
| Key | Action |
|-----|--------|
| `←/→` | Previous/next diff |
| `↑/↓` | Scroll diff |
| `Space` | Stage/unstage hunk |
| `v` | Toggle diff view |

## Rebasing
| Key | Action |
|-----|--------|
| `e` | Edit commit |
| `s` | Squash commit |
| `f` | Fixup commit |
| `d` | Drop commit |
| `r` | Reword commit |

## Search & Filter
| Key | Action |
|-----|--------|
| `/` | Search |
| `Esc` | Clear search/filter |
| `x` | Open menu |

## General
| Key | Action |
|-----|--------|
| `q` | Quit / Close panel |
| `?` | Help / All keybinds |
| `@` | Command log |
| `Shift + C` | Custom command |
| `: ` | Git command |
